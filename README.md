
# 3D Portfolio Project

## Description
A 3D portfolio website built with Three.js, showcasing interactive 3D models and animations.

## Features
- Interactive 3D environment
- Custom loading screen
- Responsive design
- Multiple project showcases
- GSAP animations

## Technologies Used
- Three.js (v0.177.0)
- Vite (v6.3.5)
- GSAP (v3.13.0)
- @seregpie/three.text-sprite (v3.2.0)

## Installation
1. Clone the repository
2. Install dependencies: bash npm install
3. Run development server: bash npm run dev
